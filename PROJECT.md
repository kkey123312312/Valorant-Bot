# Valorant-бот

## Что это

Telegram-бот: подбор агентов Valorant по рангу, карте и роли, карточка с ориентирами выбора и побед и совет GigaChat. У сентинелов, смокеров, дуэлянтов и инициаторов в карточке ещё текст под выбранную группу рангов из `agents.json`. Лайн-апы читаются из `lineups.json`: сторона (атака/защита) и сайт (A/B, на Haven ещё C и Mid, на Lotus ещё C).

## Стек и запуск

Python 3.13, aiogram 3, gigachat, python-dotenv. На 3.15 aiogram не ставится (нет wheel для aiohttp). Команда `python` может вести в заглушку Microsoft Store. Для mp4 **>50 МБ** (лимит upload Telegram) нужен **ffmpeg** в PATH — бот сжимает в 720p и кэширует в `media/lineups/`. В `lineups.json` таких роликов 34, сжатые копии лежат в `media/lineups/`. Поля `photo_url` в каталоге нет: у записи ролик (`video_url`) и ссылка на источник (`source`).

```bash
py -3.13 -m pip install -r requirements.txt
py -3.13 main.py
```

В `.env` (не в git): `BOT_TOKEN`, `GIGACHAT_CREDENTIALS`. После правок кода бота нужно остановить (Ctrl+C) и запустить снова.

## Структура файлов

- `main.py` — polling, проверка env
- `handlers.py` — сценарий и правки одного меню
- `keyboards.py`, `callbacks.py`, `states.py` — кнопки, callback, FSM
- `constants.py` — ранги, карты, роли, сайты
- `analytics.py` — карточка агентов (зашитые ориентиры) и профили из `agents.json`
- `agents.json` — у сентинелов, смокеров, дуэлянтов и инициаторов на каждую группу рангов: почему берут, сильные и слабые стороны. Термины из `GLOSSARY.md`. У инициаторов текст по словарю, без TODO. У остальных ролей механики вне словаря и частота без цифр помечены TODO. Феникс и Ёру в карточке не выходят: в META их нет.
- `lineups.py`, `lineups.json` — лайн-апы. Кэш `file_ids.json` не в git
- `lineups_view.py` — ролик: file_id, локальный `media/lineups/*.mp4`, URL (до ~20 МБ), иначе скачивание и upload
- `tools/warm_file_ids.py` — прогреть `file_ids.json` (быстрый повторный просмотр)
- `gigachat_client.py` — один клиент GigaChat на процесс

## Что работает

`/start` → ранг → карта → роль → карточка. В чате одно сообщение меню: при открытии ролика меню удаляется, «Назад» снова шлёт список; старые сообщения бота снимаются по `menu_id` / `video_id`. Совет ИИ — одно сообщение, повторный запрос его же редактирует. Карточка на русском. Подписи: выбор и победы; под ними сразу блок из `agents.json` (термины из `GLOSSARY.md`). У сентинелов, смокеров, дуэлянтов и инициаторов под выбранный ранг три строки: зачем пикают, плюсы, минусы. У инициаторов TODO в карточке нет, текст по словарю. У остальных ролей механики вне словаря и частота без цифр ещё помечены TODO. Внизу: ориентировочные данные на 23 октября 2026, не живая статистика. Лайн-апы в JSON (181): инициаторы на Haven, Ascent и Bind; на Bind ещё сентинелы Cypher, Killjoy, Vyse, Veto, Deadlock (40 mp4). Viper в меню есть, в JSON пока нет. Дальше сторона и сайт; Mid в меню на Haven и Bind. Ролик — отдельное сообщение: кэш file_id, при необходимости скачивание (до 100 МБ, заголовки для tricks.gg); тяжёлые Blitz nexus (Veto до ~95 МБ) не шлём по URL — только upload. Первый просмотр большого ролика может занять десятки секунд; повторный — по file_id. Опционально: положить сжатый mp4 в `media/lineups/` или прогреть кэш `tools/warm_file_ids.py`. Меню отвечает на клик сразу; каталог лайн-апов в памяти. База собирается из `C:\Project Vlr\lineups.json` + `lineups_bind_sentinels.json` (`tools/build_lineups_json.py`). Источник и страница — кнопками. Если по стороне мало данных, это на экране сайтов.

## Известные проблемы

- Цифры в карточке — округлённые ориентиры с датой внизу, не живая выгрузка Tracker.gg / VLR / OP.GG.
- Ascent есть в JSON лайн-апов, в том числе Mid, но не в меню карт бота.
- Viper и лайн-апы сентинелов на картах кроме Bind в JSON пока пустые.
- Запасной текст без разбора HTML: если mp4 не вставился, теги видны как текст.
- `file_ids.json` — локальный кэш file_id на диске этой машины; без прогрева первый показ тяжёлых роликов (Veto nexus) долгий.
- FSM в памяти: перезапуск бота сбрасывает диалог.
- `verify_ssl_certs=False` у GigaChat.
- Пустой файл `venv.py` не используется.
