# Valorant-бот

## Что это

Telegram-бот: подбор агентов Valorant по рангу, карте и роли, карточка с ориентирами выбора и побед и совет GigaChat. У сентинелов, смокеров, дуэлянтов и инициаторов в карточке ещё текст под выбранную группу рангов из `agents.json`. Лайн-апы читаются из `lineups.json`: сторона (атака/защита) и сайт (A/B, на Haven ещё C и Mid, на Lotus ещё C).

## Стек и запуск

Python 3.13, aiogram 3, gigachat, python-dotenv. На 3.15 aiogram не ставится (нет wheel для aiohttp). Команда `python` может вести в заглушку Microsoft Store.

```bash
py -3.13 -m pip install -r requirements.txt
py -3.13 main.py
```

В `.env` (не в git): `BOT_TOKEN`, `GIGACHAT_CREDENTIALS`. После правок кода бота нужно остановить (Ctrl+C) и запустить снова.

## Структура файлов

- `main.py` — polling, проверка env
- `handlers.py` — сценарий и правки одного меню
- `keyboards.py`, `callbacks.py`, `states.py` — кнопки, callback, FSM
- `constants.py` — ранги, карты, роли, сайты
- `analytics.py` — карточка агентов (зашитые ориентиры) и профили из `agents.json`
- `agents.json` — у сентинелов, смокеров, дуэлянтов и инициаторов на каждую группу рангов: почему берут, сильные и слабые стороны. Термины из `GLOSSARY.md`; механики вне словаря и частота без цифр помечены TODO. Феникс и Ёру в карточке не выходят: в META их нет.
- `lineups.py`, `lineups.json` — лайн-апы. Кэш `file_ids.json` не в git
- `lineups_view.py` — ролик: сохранённый file_id, прямая ссылка, фото, иначе текст
- `gigachat_client.py` — один клиент GigaChat на процесс

## Что работает

`/start` → ранг → карта → роль → карточка. Меню правится на месте. Совет ИИ — одно сообщение, повторный запрос его же редактирует. Карточка на русском. Подписи: выбор и победы; под ними сразу блок из `agents.json` (термины из `GLOSSARY.md`). У сентинелов, смокеров, дуэлянтов и инициаторов под выбранный ранг три строки: зачем пикают, плюсы, минусы. Механики вне словаря и частота без цифр помечены TODO. Внизу: ориентировочные данные на 23 октября 2026, не живая статистика. Лайн-апы в JSON (141): инициаторы Sova, Fade, Breach, KAY/O, Gekko на Haven, Ascent и Bind; у каждой записи прямой mp4. Viper и Сайфер в меню есть, записей в JSON пока нет — заглушка. Дальше сторона и сайт, на Haven ещё Mid. Ролик — отдельное сообщение: file_id, затем mp4, затем фото, иначе текст. Источник и страница — кнопками. Если по стороне мало данных, это на экране сайтов.

## Известные проблемы

- Цифры в карточке — округлённые ориентиры с датой внизу, не живая выгрузка Tracker.gg / VLR / OP.GG.
- Ascent есть в JSON лайн-апов, в том числе Mid, но не в меню карт бота.
- Viper, Сайфер и остальные карты маппула в JSON лайн-апов пока пустые.
- Запасной текст без разбора HTML: если mp4 и фото не вставились, теги видны как текст.
- `file_ids.json` — локальный кэш file_id на диске этой машины.
- FSM в памяти: перезапуск бота сбрасывает диалог.
- `verify_ssl_certs=False` у GigaChat.
- Пустой файл `venv.py` не используется.
