# Valorant-бот

## Что это

Telegram-бот: подбор агентов Valorant по рангу, карте и роли, карточка с ориентирами выбора и побед и совет GigaChat. У сентинелов в карточке ещё текст под выбранную группу рангов из `agents.json`. Лайн-апы читаются из `lineups.json`: сторона (атака/защита) и сайт (A/B, на Haven и Lotus ещё C).

## Стек и запуск

Python 3.13, aiogram 3, gigachat, python-dotenv. На 3.15 aiogram не ставится (нет wheel для aiohttp). Команда `python` может вести в заглушку Microsoft Store.

```bash
py -3.13 -m pip install -r requirements.txt
py -3.13 main.py
```

В `.env` (не в git): `BOT_TOKEN`, `GIGACHAT_CREDENTIALS`. После правок кода бота нужно остановить (Ctrl+C) и запустить снова.

## Структура файлов

- `main.py` — polling, проверка env
- `handlers.py` — сценарий и правки одного меню
- `keyboards.py`, `callbacks.py`, `states.py` — кнопки, callback, FSM
- `constants.py` — ранги, карты, роли, сайты
- `analytics.py` — карточка агентов (зашитые ориентиры) и профили из `agents.json`
- `agents.json` — у сентинелов и смокеров на каждую группу рангов: почему берут, сильные и слабые стороны. Термины из `GLOSSARY.md`; механики вне словаря и частота без цифр помечены TODO.
- `lineups.py`, `lineups.json` — лайн-апы
- `gigachat_client.py` — один клиент GigaChat на процесс

## Что работает

`/start` → ранг → карта → роль → карточка. Меню правится на месте. Совет ИИ — одно сообщение, повторный запрос его же редактирует. Карточка на русском. Подписи: выбор и победы; под ними сразу блок из `agents.json` (термины из `GLOSSARY.md`). У сентинелов и смокеров под выбранный ранг три строки: зачем пикают, плюсы, минусы. Механики вне словаря и частота без цифр помечены TODO. У остальных ролей этого блока нет. Внизу: ориентировочные данные на 23 октября 2026, не живая статистика. Лайн-апы фильтруются по роли: инициатор Sova/Fade, смокер Viper, сентинел Сайфер. Дальше сторона и сайт. У Сайфера на Haven ~41 ролик; ссылка на tracker.gg открывается кнопкой, прямое видео шлётся только если URL — файл.

## Известные проблемы

- Цифры в карточке — округлённые ориентиры с датой внизу, не живая выгрузка Tracker.gg / VLR / OP.GG.
- Ролики tracker.gg — страницы гайдов, не mp4. Telegram их как видео не вставляет.
- Сайт часто угадывается по названию, если в JSON нет поля `site`.
- У дуэлянта агентов нет. Ascent есть в JSON, но не в меню карт.
- FSM в памяти: перезапуск бота сбрасывает диалог.
- `verify_ssl_certs=False` у GigaChat.
- Пустой файл `venv.py` не используется.
